## 🔥 HydraWall — My Research Project

### 🛡️ HydraWall — A Regenerative AI Firewall  
A next-gen cybersecurity system that:

- Detects anomalies using ML  
- Regenerates firewall rules dynamically  
- Mutates defensive layers on every attack  
- Rotates cryptographic states  
- Uses safe SLM-based reasoning  
- Prevents attacker learning loops  

📄 **Published Paper (Zenodo DOI):**
